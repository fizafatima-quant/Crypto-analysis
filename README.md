# Crypto Analysis Toolkit 🚀

A Python-based toolkit for **cryptocurrency technical analysis**, designed to fetch market data, compute indicators, and generate trading signals.  
Built with a modular structure and scalable design, this project supports ongoing development across multiple branches (data fetching, indicator calculation, backtesting, and visualization).  

---

## 🔑 Features

- **Data Fetching**  
  - Pulls OHLCV data from Binance API  
  - Supports multiple crypto pairs and timeframes  

- **Technical Indicators**  
  - RSI (Relative Strength Index)  
  - MACD (Moving Average Convergence Divergence)  
  - Bollinger Bands  
  - Extendable for custom indicators  

- **Signal Generation**  
  - Rule-based buy/sell signals from indicator thresholds  
  - Configurable strategies  

- **Backtesting (in-progress branch)**  
  - Apply strategies on historical datasets  
  - Performance metrics: ROI, Sharpe Ratio, Max Drawdown  

- **Visualization (planned)**  
  - Interactive charts for indicators and trade signals
